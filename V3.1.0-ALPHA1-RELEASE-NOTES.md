# AnchorWeight v3.1.0-alpha.1 — AI Agent Access Controls

v3.1 begins with explicit controls for declared AI crawlers and user-triggered AI fetchers.

## Added

- Request-scoped AI Agent Access Policy with `allow`, `observe`, and `deny`.
- Purpose defaults for model training, search indexing, user retrieval, and general AI automation.
- Per-family overrides using `provider:family=action` rules.
- OpenAI: GPTBot, OAI-SearchBot, ChatGPT-User, OAI-AdsBot.
- Anthropic: ClaudeBot, Claude-SearchBot, Claude-User.
- Perplexity: PerplexityBot, Perplexity-User.
- Google: Google-Agent, Google-GeminiNotebook, legacy Google-NotebookLM, Google-CloudVertexBot.
- Google-Extended robots.txt guidance without conflating it with Googlebot.
- `npm run ai-agents:check` static safety/contract gate.
- `npm run ai-agents:robots` robots.txt guidance generator.
- Agent Passport `aiAgentControls` capability.

## Safety posture

- Defaults remain observation-only.
- AI-agent enforcement requires an explicit enforcement flag and disabling the AI-agent-specific shadow mode.
- A User-Agent declaration never grants trust or bypass privileges.
- Declared-agent deny does not require trusted client IP because it affects only the current self-declared request.
- Existing client-scoped Policy Engine enforcement remains independently gated by trusted client identity and existing release controls.
- `/robots.txt` remains readable even by a declared agent that would otherwise be denied.

## Not in alpha.1

- Provider IP verification or Web Bot Auth verification.
- Automatic remote fetching of vendor IP ranges.
- Automatic rewriting of an origin's robots.txt.
- Broad blocking of Googlebot or normal search crawlers.
- Changes to v3.0 policy action ladder, persistence schema, or client-scoped enforcement eligibility.

## Compatibility fix 1

- Missing `aiAgentFamilyRules` now defaults to an empty list during validation, preserving compatibility with v3.0-era config objects and the operator-settings reader.
- Added regression coverage for conservative config validation and operator-settings compatibility.
