# AnchorWeight v3.1.0-alpha.2 Release Notes

## Verified AI-Agent Identity

Alpha.2 adds provider-published network verification on top of alpha.1 AI Agent Access Controls.

### Added
- OpenAI family-specific network verification.
- Perplexity family-specific network verification.
- Google category-specific network verification for Google-Agent, Gemini Notebook, and Google-CloudVertexBot.
- Explicit Anthropic `provider_ranges_unpublished` posture.
- IPv4 and IPv6 CIDR matching.
- Bounded in-process range cache and request timeout.
- Verification status in AI-agent policy telemetry.
- Agent Passport AI Agent Controls v2 verification descriptor.
- Dedicated verification gate and regression tests.

### Preserved
- Declared User-Agent never grants trust.
- AI-agent `allow` never bypasses normal AnchorWeight defenses.
- Request-scoped `deny` does not require successful network verification.
- Degraded proxy identity never produces a verified result.
- v3.0 frozen privacy and client-scoped enforcement invariants remain intact.
- Google Web Bot Auth is documented as experimental and is not overstated as implemented.
