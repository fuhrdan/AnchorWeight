# AnchorWeight v3.1.0-alpha.4 — AI-Agent Observability & Operator Dashboard

Alpha.4 makes the AI-agent controls measurable before v3.1 moves toward release hardening.

## Added

- bounded process-local AI-agent access observatory
- declared / verified / unverified / unavailable counters
- allow / observe / would-deny / denied outcome counters
- provider and family breakdowns
- purpose and policy-source aggregation
- bounded recent decision summaries
- authenticated `GET <basePath>/api/ai-agents`
- `aiAgentTraffic` in the existing authenticated stats response
- AI Agent Access Observatory dashboard panel
- Agent Passport AI Agent Controls v4 observability descriptor
- dedicated `npm run ai-agents:observability-check` release gate

## Safety properties

- no raw IP retention or exposure
- no raw User-Agent retention or exposure
- no path, query, cookie, origin, or credential retention
- no state-schema migration
- no automatic allow or block behavior
- no enforcement path
- no change to the alpha.1 declaration policy
- no change to the alpha.2 verifier
- no change to the alpha.3 verification-aware policy semantics

## Shared-host posture

The observatory is deliberately small and resets at process restart. This avoids adding persistent write pressure or background work on constrained cPanel/Passenger deployments.
