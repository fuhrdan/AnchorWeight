# AnchorWeight v3.1.0-alpha.5 — AI Agent Policy Manager

Alpha.5 turns the v3.1 AI-agent policy stack into an operator workflow while preserving the existing safety contract.

## Added
- Authenticated AI Agent Policy Manager dashboard panel.
- Purpose-default editor for training, search, user retrieval and automation.
- Family and verification-status rule editors.
- Conflict detection and bounded validation.
- Shadow-only preview against the Alpha.4 recent decision buffer.
- Private 0600 saved-draft file.
- Canonical JSON and environment export.
- Authenticated/CSRF-protected policy-manager API.

## Not added
- No dashboard enforcement switch.
- No automatic mutation of the live runtime config.
- No raw IP, User-Agent, path, query, cookie or credential retention.
- No persistence of observed traffic.

The exported environment always keeps AI Agent Controls in shadow mode with enforcement disabled. Operators must make any later enforcement transition explicitly outside this manager.
