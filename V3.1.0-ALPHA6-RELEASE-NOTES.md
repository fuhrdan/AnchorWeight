Alpha.6 adds a controlled deployment plan for saved alpha.5 AI-agent policy drafts.

Highlights:

- exact live-vs-draft policy diff
- bounded replay against recent alpha.4 observations
- explicit risk flags for deny/allow expansion and verification edge cases
- stable plan IDs that reject stale confirmation
- private rollback snapshot before preparation
- mode-0600 shadow environment and rollback environment artifacts
- exact confirmation phrases and separate high-risk acknowledgement
- authenticated, CSRF-protected dashboard workflow
- no runtime mutation, automatic restart, cPanel editing, or enforcement-enable control
