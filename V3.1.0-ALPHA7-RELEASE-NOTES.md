# AnchorWeight v3.1.0-alpha.7 Release Notes

## AI Agent Burn-In & Readiness

Alpha.7 is the release-hardening checkpoint for the v3.1 AI-agent work.

It consolidates the alpha.1-alpha.6 controls into one offline readiness gate:

```sh
npm run ai-agents:burnin-check
```

A clean result reports:

```text
READY FOR v3.1 BETA REVIEW
```

This is **not** an enforcement-readiness grant. Active enforcement remains a separate, explicit operator decision and existing client-identity safety requirements remain unchanged.

- `src/ai-agent-burnin-readiness.js`

- shadow deployment/rollback safety verification
