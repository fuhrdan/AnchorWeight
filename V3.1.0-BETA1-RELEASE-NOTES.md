# AnchorWeight v3.1.0-beta.1 Release Notes

## Stabilization begins

v3.1.0-beta.1 promotes the alpha.1-alpha.7 AI-agent stack into beta validation without adding new enforcement behavior.

### Beta.1 focus

- preserve the complete alpha.7 burn-in evidence;
- move release metadata to the `beta` channel;
- add a beta stabilization/readiness gate;
- verify the frozen v3.0 contract and privacy invariants again;
- verify policy-manager and controlled-deployment shadow safety;
- verify operator/dashboard surfaces remain non-enforcing;
- require source-manifest release verification;
- document a repeatable beta validation and rollback workflow.

### New gate

```sh
npm run ai-agents:beta-check
```

A clean beta gate ends with:

```text
AnchorWeight 3.1.0-beta.1 AI Agent Beta Stabilization PASS (... invariants checked)
READY FOR v3.1 BETA VALIDATION
Active AI deny enforcement remains a separate explicit operator decision.
```

The gate is offline and non-mutating. It does not authorize enforcement.

### Compatibility and safety

Beta.1 retains:

- AI-agent declaration policy semantics from alpha.1;
- provider verification from alpha.2;
- verification-aware policy from alpha.3;
- bounded privacy-safe observability from alpha.4;
- staged policy management from alpha.5;
- controlled shadow deployment and rollback preparation from alpha.6;
- alpha.7 family-canary/frozen-contract burn-in;
- the v3.0 frozen contract;
- existing HawkHost client-identity safety restrictions.
