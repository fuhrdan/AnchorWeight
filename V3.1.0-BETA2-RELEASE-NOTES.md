# AnchorWeight v3.1.0-beta.2 Release Notes

## Production Shadow Validation

Beta.2 moves validation from the package itself to the deployed shadow operating workflow.

No new AI-agent request-enforcement behavior is added.

### Added

- offline `ai-agents:beta2-check` gate;
- live `ai-agents:production-check` validator;
- `/live` and Agent Passport contract checks;
- `/robots.txt` availability check;
- normal-browser non-regression canary;
- 12-family live AI-agent canary matrix;
- optional authenticated AI operator API validation;
- environment-only dashboard-token handling;
- redacted pre/post restart state capture and comparison;
- production shadow/RC-review readiness model;
- production validation documentation.

### Safety

Beta.2:

- requires global shadow mode for production validation;
- requires public Agent Passport AI enforcement to be off;
- never enables enforcement;
- never edits cPanel/hosting configuration;
- never restarts Passenger/Node;
- never accepts a dashboard token on the command line;
- treats degraded HawkHost client identity as a documented constraint;
- preserves the frozen v3.0 contract and all beta.1 prerequisites.

### Gates

```sh
npm run ai-agents:beta2-check
npm run ai-agents:production-check
```

The production check is intentionally not part of `release-check.js`, because source/package verification must remain deterministic and offline. Run the production check explicitly against the deployed beta.2 instance.
