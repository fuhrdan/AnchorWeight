# AnchorWeight v3.2.0-alpha.1 — Bulk Scrape / Site Extraction Detection

v3.2.0-alpha.1 starts the v3.2 production-hardening line with a new observation-only site-extraction detector.

## Added

- bounded site-extraction state per client/session profile;
- unique URL breadth and unique-request-ratio evidence;
- five-minute route breadth evidence;
- normalized route-family concentration for ID/slug enumeration;
- numeric resource enumeration evidence;
- cookie-continuity and document-heavy collection evidence;
- browser Fetch Metadata absence as weak supporting evidence;
- machine-regular timing evidence;
- command-line client declarations as weak supporting evidence;
- 404 enumeration and bulk-download evidence;
- public profile projection with no raw path/query/cookie/User-Agent retention;
- Agent Passport `siteExtractionDetection` capability;
- `npm run site-extraction:check` safety/readiness gate.

## Deliberately not added

- no blocking;
- no throttling;
- no quarantine;
- no decoy action;
- no Policy Engine input;
- no Resource Budget input;
- no legacy Bot DNA score mutation;
- no new environment/configuration switch.

A spoofed browser User-Agent can still be identified by extraction behavior, while a small number of legitimate curl requests remain below the detector threshold.
