# AnchorWeight v3.2.0-alpha.2 — Site Extraction Observatory

v3.2.0-alpha.2 turns the alpha.1 bulk-scrape detector into an operator-visible, production-tuning surface while preserving the observation-only safety boundary.

## Added

- aggregate Site Extraction Observatory built only from sanitized public profiles;
- level distribution across `none`, `watch`, `elevated`, `likely_bulk_scrape`, and `high_confidence_bulk_scrape`;
- likely/high-confidence candidate counts;
- five-minute freshness count;
- average and maximum extraction score;
- bounded reason distribution;
- ranked candidate table with redacted evidence;
- authenticated dashboard panel;
- dedicated alpha.2 invariant check and unit tests;
- explicit privacy contract for observatory aggregation.

## Still deliberately not added

- no blocking;
- no throttling;
- no quarantine;
- no decoy action;
- no Policy Engine input;
- no Resource Budget input;
- no legacy Bot DNA score mutation;
- no raw path/query/cookie/User-Agent/IP retention in the observatory.

## Deployment goal

Use the new dashboard surface to collect production evidence and tune false positives before any later policy-simulation bridge is considered.

The v3 frozen enforcement contract remains unchanged.
