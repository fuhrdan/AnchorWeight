Choose an approved origin

Only an exact origin approved in cPanel may be selected. To add another destination, update AW_SETUP_ALLOWED_ORIGINS in cPanel and restart the application.

Choose routing mode

Path-based upstream routes

Routes are exact segment prefixes such as /api. Origins must be approved in AW_ROUTE_ALLOWED_ORIGINS. Maximum 16 routes.

If enabled, normal site requests are forwarded to the selected origin. Keep your origin private if using Silent Quarantine, and verify your domain routing before enabling this on a public site.

Shadow/Enforce Mode is deliberately not editable through this wizard.

Review and validate

Validate checks exact origin approval and configuration schema. Applying performs the prepared proxy switch, then saves a private settings file for restart persistence.
